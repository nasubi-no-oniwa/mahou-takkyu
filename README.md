# 魔法の球 卓球

線を描けば、それが魔球になる。「魔法の球」の卓球版。

- サーブ：ラケットの球から線を描いて、魔球サーブとして登録する。自分のコートで1回、相手のコートで1回はずませて、相手のうしろの光る箱で止める
- 回転（なし・上・下・左・右・ナックル）と球速（20〜100km/h）を選べる。回転は2回目のバウンドのあとに効いてくる
- レシーブ：合言葉で魔球を呼び出し、ボールが来た所でスワイプして打ち返す。回転は打つまで分からない。回転に合った振り方でないと、ネット・アウト・サイドアウトになる
- 3本のうち1本でも返せば勝ち。返されていない魔球のランキング（今日・全期間）
